# Photographs Directory for Aswathy's Birthday Website

To add Aswathy's actual photographs to the website, place your image files here in `/public/images/`:

## 1. Main Portrait
- `aswathy-portrait.jpg` — The starring centerpiece portrait on the very first screen (Hero) and archival features. An elegant SVG fallback is provided automatically at `aswathy-portrait.svg` until your personal photo is placed. You can also click "Preview Your Photo" in the browser to preview any image instantly!

## 2. Cinematic Photo Gallery (Chapter V)
- `gallery-1.jpg` — Supporting tall portrait (e.g., radiant smiling memory).
- `gallery-2.jpg` — Wide landscape photo (e.g., golden hour or scenic memory).
- `gallery-3.jpg` — Vertical editorial portrait (e.g., candid grace).
- `gallery-4.jpg` — Polaroid keepsake frame (e.g., nostalgic or fun moment).

## 3. Memory Scrapbook (Chapter VI)
- `scrapbook-1.jpg` — Memory Journal Item 1 ("A moment worth keeping.")
- `scrapbook-2.jpg` — Memory Journal Item 2 ("A little piece of happiness.")
- `scrapbook-3.jpg` — Memory Journal Item 3 ("One for the memory book.")
- `scrapbook-4.jpg` — Memory Journal Item 4 ("A beautiful moment, preserved.")

---

### Notes:
- If any image file is missing, the website automatically displays an intentional editorial mat with a quote and botanical emblem. No broken image icons will ever appear.
- All image filenames, captions, tags, and dates can also be customized directly in `/src/data/birthdayContent.ts`.
